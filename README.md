# Deriv bot XML collection

A collection of XML bot files for exploring automated trading strategies on Deriv. The files include digit, even/odd, rise/fall, over/under, and recovery variants. Some filenames describe experiments or past outcomes; they are not verified performance results.

## Use

1. Review an individual XML file before importing it into a compatible Deriv bot environment.
2. Test it in a demo account and inspect its stake progression, stop conditions, and loss behavior.
3. Set risk limits appropriate to your own use. Do not assume a strategy is profitable or safe in live trading.

There is no application build, automated test suite, audited backtest, or verified performance report in this repository. The XML files themselves are the source of truth for each strategy. Contributions should identify the exact file changed and explain the strategy and risk implications.
